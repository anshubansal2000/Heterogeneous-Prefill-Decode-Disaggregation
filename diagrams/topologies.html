A · Our setup — single node (Config E): CPU prefill → GPU decode

One pod. KV never leaves the box: DRAM → PCIe → HBM. No NIC, no KV store, no cluster.

B · Production scale-out: pools of CPU prefill + Mooncake Store/TE + pool of decode GPUs

Prefill and decode are separate autoscaled fleets, connected by a shared KV pool over a network fabric. Ratios (N prefill : M decode) are tuned to traffic.

C · Memory hierarchy — where "resident" means, and who fits where

"The model must be resident in RAM" = it must sit in DRAM (for CPU compute) or HBM (for GPU compute). SSD only stores it at rest. The CPU/GPU cannot compute out of SSD.
